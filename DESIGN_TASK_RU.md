# CodeShelf — Задание на дизайн: страницы веб-интерфейса (Figma)

CodeShelf — интернет-магазин книг по программированию (также продаётся немного классической
художественной литературы). Пожалуйста, нарисуй в Figma страницы, перечисленные ниже. Визуальный стиль,
раскладка и компоненты — на твоё усмотрение. Этот список описывает только **какие страницы есть и что
на каждой должно быть**.

Общие требования из плана проекта:

- Десктопная и мобильная версии (раскладка должна работать от ширины 360 px).
- Интерфейс только на английском языке (поэтому надписи на кнопках ниже оставлены на английском).
- Оформление заказа — не больше 3 шагов.
- Цены в злотых (PLN).

---

## Общие элементы (на каждой странице)

- **Шапка:** логотип, поле поиска, иконка корзины с количеством товаров, Login/Register (или имя
  пользователя со ссылками на Profile, My orders и Log out), ссылка на панель администратора — только
  для админов.
- **Подвал (футер).**

---

## Страницы для покупателя

### 1. Каталог (главная страница)
- Список книг с постраничной навигацией.
- Поиск по названию, автору или ISBN.
- Фильтры: язык программирования, тема, уровень (beginner / intermediate / advanced), «только в наличии».
- Сортировка: по названию, цене, году издания, по новизне.
- Карточка книги: обложка, название, автор, цена, кнопка «Add to cart», состояние «нет в наличии».
- Состояние «No books found» (книги не найдены).

### 2. Страница книги
- Обложка, название, автор, описание.
- Издательство, год, количество страниц, ISBN, уровень, категории.
- Цена и наличие (в наличии / нет в наличии).
- Выбор количества и кнопка «Add to cart».

### 3. Вход
- E-mail, пароль, кнопка «Log in», ссылка на регистрацию, сообщение об ошибке при неверных данных.

### 4. Регистрация
- Имя, e-mail, пароль, кнопка «Create account», ссылка на вход, сообщения об ошибках в полях.

### 5. Корзина
- Список книг: обложка, название, автор, цена, выбор количества, кнопка удаления, сумма по позиции.
- Итоговая сумма заказа и кнопка «Checkout».
- Состояние пустой корзины.
- Сообщение, когда на складе недостаточно экземпляров.

### 6. Оформление заказа (3 шага)
1. **Проверка:** книги, количество и итоговая сумма.
2. **Доставка и оплата:** имя получателя, адрес доставки, способ оплаты
   (оплата при получении / картой — тестовый платёж).
3. **Подтверждение:** сообщение «Thank you», номер заказа, заказанные книги, сумма, статус.

### 7. Профиль
- Изменение имени и e-mail.
- Смена пароля (текущий пароль, новый пароль).

### 8. Мои заказы
- Список заказов: номер заказа, дата, статус, количество книг, сумма.
- Пустое состояние («You have no orders yet» — у вас пока нет заказов).

### 9. Детали заказа
- Номер заказа, дата, статус, способ оплаты, получатель и адрес.
- Книги с количеством, ценой и суммой по позиции; итоговая сумма заказа.
- Кнопка «Cancel order» (только для заказов в статусе pending), кнопка «Pay» (только для неоплаченных
  заказов с оплатой картой).

## Страницы администратора (только для администраторов)

### 10. Админка — Книги
- Таблица: обложка, название, автор, цена, остаток на складе, действия (редактировать, удалить).
- Поиск и кнопка «Add book».

### 11. Админка — Добавление / редактирование книги
- Форма: название, автор, описание, ISBN, издательство, год, количество страниц, уровень, цена,
  остаток на складе, категории.
- Загрузка обложки с предпросмотром.
- Кнопки Save и Delete.
- Сообщение о том, что книгу нельзя удалить, потому что её уже заказывали.

### 12. Админка — Категории
- Список категорий: название, тип (язык / тема), количество книг.
- Добавление, редактирование и удаление категории.

### 13. Админка — Заказы
- Таблица: номер заказа, дата, покупатель, сумма, статус.
- Фильтр по статусу и поиск (имя покупателя, e-mail, адрес, номер заказа).

### 14. Админка — Детали заказа
- Покупатель (имя, e-mail), получатель, адрес, способ оплаты.
- Заказанные книги с количеством и ценами, итоговая сумма.
- Смена статуса: pending → paid / shipped / cancelled, paid → shipped / cancelled,
  shipped → delivered.
